# ホテル向け展開（OTA連携＋スマートロックPIN自動発行）調査レポート

調査日: 2026-09-04。価格は各社サイト/比較記事の掲載値で、改定される可能性あり。「不確か」と書いた項目は一次情報を直接確認できていません。

## 1. OTAへの直接API接続は可能か

結論: 個人開発システムがOTAの「施設側（在庫・予約管理）API」に直接つなぐことは、事実上どのOTAも不可。全てサイトコントローラー（チャネルマネージャー）経由が前提。

| OTA | 直接接続 | 補足 |
|---|---|---|
| 楽天トラベル | 不可 | 公開「楽天トラベルAPI」は空室検索のアフィリエイト用。施設側接続はサイトコントローラーが「R-Connect」で接続。個人が新規取得できるかは非公開（ほぼ無理と推定） |
| じゃらん | 不可 | 「じゃらんWebサービス」も検索用。施設側はサイトコントローラー経由 |
| Booking.com | 不可（施設単体） | Connectivity APIはチャネルマネージャー/PMS事業者向け。PCI/PII準拠・複数施設実績が条件。新規プロバイダー受付停止中との情報あり（不確か） |
| Expedia | 不可（施設単体） | EG Connectivity Hubでエンドツーエンド認定が必要 |
| Airbnb | 不可 | 公開APIなし。承認パートナー限定 |

## 3. 法規制（無人チェックイン要件）

### 旅館業法（2025年4月改正施行）
フロント不設置は以下4条件を全て満たす場合に可能:
1. ICT機器による本人確認と宿泊者名簿記録（ビデオ通話またはタブレット/自動チェックイン機で顔と本人確認書類を確認・録画）
2. 鍵の適切な受渡し（スマートロック等）
3. 緊急時に迅速に駆けつけられる体制（「おおむね10分」は自治体運用の目安。不確か）
4. 宿泊者・近隣との連絡対応体制

- 宿泊者名簿: 氏名・住所・職業・国籍・旅券番号等。外国人は旅券写し保存。電子保存可、保存3年
- 自治体の上乗せ条例で無人フロント不可の場合あり。秋田県/秋田市の条例は未確認。着手前に所轄保健所へ確認必須
- 既存許可施設が無人化する場合は変更届

### 住宅宿泊事業法（民泊新法）
顔と旅券が鮮明に確認でき、画像が施設内または近傍から発信されていることが条件。年間180日制限。ホテル運営なら旅館業法が本線。

## 4. 既存アプリ流用のアーキテクチャ案

```
OTA(楽天/じゃらん/Booking/Expedia/Airbnb)
   → Beds24（在庫・料金同期、予約集約、自動部屋割り）
   → Beds24 予約Webhook → Vercel API（既存admin.ts型のaction分岐に相乗り）
   → Firestore: hotelBookings（既存checkinsと分離）
   → RemoteLOCK API: 客室デバイスに access_guest（チェックイン15:00〜チェックアウト10:00）
   → ゲスト通知: メール（Resend既存）／LINE（既存notify.ts）
   → 事前チェックイン画面（既存LIFFにページ追加）: 名簿入力・身分証撮影
```

注意点:
- Vercel HobbyのAPI 12本上限に達しているため、新規エンドポイントは既存action分岐に相乗りするかProプランへ
- Beds24 Webhookは平均1分遅延。当日予約の即時PINにはポーリング併用が安全
- RemoteLOCKの時刻はタイムゾーンなしISO 8601（既存の422対処知見がそのまま活きる）
- LINEミニアプリからの直販を残す場合はBeds24 API v2で予約を書き込み在庫を減らす

### 3案比較（10室想定）

| | 小（最小構成） | 中（推奨） | 大（本格無人ホテル） |
|---|---|---|---|
| 構成 | Beds24×RemoteLOCK公式連携のみ、コードなし。通知はBeds24メール。本人確認は別運用 | Beds24 Webhook→既存Vercel API→RemoteLOCK PIN→LINE/メール通知。LIFFに事前チェックイン（名簿＋身分証画像）追加。管理画面に宿泊タブ | 中案＋タブレットのビデオ通話/自動チェックイン機（maneKEY等）で法令要件をベンダー製品で担保 |
| 月額目安 | Beds24 約6,000円＋RemoteLOCK 2,200円×10＝約28,000円 | 約31,000円（＋Vercel Pro） | 約54,000円（＋maneKEY 2,250円×10） |
| 初期費用 | RemoteLOCK 500i 66,000円×10＋取付45,000円×10＝約111万円 | 同上 | 同上＋maneKEY端末＋工事 |
| 実装工数 | 0.5〜1週間 | 3〜5週間 | 6〜10週間 |

## 主な不確定事項（要確認）
1. Booking.comの新規コネクティビティ受付停止の現況（Beds24経由なら影響なし）
2. 秋田県・秋田市の旅館業法施行条例にフロント要件の上乗せがあるか（保健所へ確認）
3. ねっぱん/TL-リンカーンへの個人開発システム新規接続可否と費用
4. AirHost・KEY STATIONの現行料金
5. 「10分駆けつけ」の法令上の根拠
