# 売上集計・RPA用売上CSV 確認結果

- 実施日: 2026-11-25（同日、イベント参加費・登録料／更新料の決済方法のご訂正を反映）
- 対象: 管理画面「売上」タブ（日別）／RPA用売上CSV／経理用CSV

## 1. ご質問への回答

### ① イベント・登録料／更新料はどの表に含まれるか

これまでは、どの表にも含まれていませんでした。本システムで決済していたのは施設予約の利用料だけだったためです。

2026-11-25 のご訂正（支払いはすべてクレジットカードまたは PayPay。計上日は決済された日。スタッフの手作業は極力なくす）に合わせ、次の形にしました。

**イベント参加費**

- 参加費のあるイベントは、申込みのときにクレジットカードまたは PayPay で決済します。決済が終わった時点で申込み完了です
- 決済された日の売上として、「イベント参加費」で自動的に入ります

**登録料／更新料（マンスリーサブスク会員）**

- 会員がアプリの「マイ予約」からカードを登録して申し込むと、その日に月額（3,630 円）を決済し、以後は毎月の同じ日（更新日）に自動で決済します
- 初回の決済を「登録料」、2 回目以降を「更新料」として、決済された日の売上に自動的に入ります
- 毎月の自動決済はクレジットカードのみです（PayPay は決済会社の仕様で、毎月の自動決済に使えません）
- 解約とカードの変更は、会員がアプリからできます。解約しても次回更新日までは会員のままで、以後の請求はありません
- 更新日に決済できなかったときは、本人と管理者に LINE で知らせ、数日おきに自動で再決済します
- 申込みの受付は、管理画面の「会員」タブで会員区分ごとに始められます（初めは止めてあります）

**出る場所**

イベント参加費・登録料・更新料とも、スタッフの入力は要りません。決済された日に、次のすべてへ同じ金額で出ます。

- 売上タブの合計・日別・月別・拠点別
- 経理用CSV の月次サマリー（⑥ やばせ その他の売上、⑦ ASP その他の売上。種別ごとの内訳つき）と、一括出力の「その他の売上 明細」
- RPA用売上CSV（「売上種別」がイベント参加費／登録料／更新料、「支払方法」がオンライン決済）

**銀行振込で受け取った分**

行政関連の団体や、カード決済エラーで銀行振込になった分だけ、売上タブの「その他の売上」の欄で入力します（日付・拠点・種別・受け取り方法・金額・メモ）。入力した分も、上と同じ場所に同じ金額で出ます。決済から自動で入った行には「自動」と出て、消せません。

### ② RPA用売上CSV について

**日次の売上表と同じ数字が出るか**

確認したところ、これまでの作りでは一致しませんでした。売上タブは「利用日」で数え、RPA用売上CSV は「決済した日」で、しかもカード決済分だけを数えていたためです。

「利用日で計上する」というご方針に合わせて、RPA用売上CSV を売上タブと同じ数え方に直しました。2 つは同じ集計の決まりを共有しているので、同じ日・同じ期間であれば必ず同じ金額になります。

**テストデータ**

実際の使われ方を想定したテストデータを、2026-11-17（火）〜11-23（月・祝）の 1 週間分入れました。予約 22 件と、その他の売上 4 件です。予約者名とメモはすべて「【テスト】」で始まります。

- 一般のカード決済（ASP 体育館・トレーニングルーム貸切／相席、やばせ体育館）
- 定期団体（S-01）の請求書払い（1 時間あたり 275 円引き）
- キャンセル（返金済み）2 件、未決済 1 件 … 売上には数えない
- 平日の昼夜またぎ（16:00〜18:00）、土日、祝日（11/23）
- 申込日と利用日が離れている予約（2 週間前の申込など）
- その他の売上 4 件（登録料 1,100 円、イベント参加費 6,600 円、更新料 2,200 円、月会費 5,500 円）… 銀行振込などで受け取った分を「その他の売上」の欄で入力した場合の例です。カード・PayPay で決済された分は、入力しなくても同じ形で入ります

利用日が過去のため、空き枠や鍵には影響しません。確認が終わりましたら、こちらで一括削除します。

**CSV 一番下の合計行**

削除しました。見出し行のあとは明細だけです。

**「区分」は「支払い状況」か**

これまでの「区分」は、その行が「決済」か「返金」かを表す列で、支払い状況ではありませんでした（返金はマイナスの金額の行）。

今回の修正で、この列はなくなりました。新しい CSV に出るのは**売上に数えるものだけ**で、キャンセル・未決済の予約は出ません。RPA 側で区分を見て行を除外する必要はなく、「金額」をそのまま足せば売上になります。

代わりに「売上種別」と「支払方法」の列があります。売上種別は 施設利用／イベント参加費／登録料／更新料／月会費／その他、支払方法は オンライン決済／請求書払い／現金／振込 などです。どちらも内訳を見るための列で、どの値でも売上に数えます。

## 2. RPA用売上CSV の新しい形

URL はこれまでと同じです（管理画面 売上タブ「RPA用 売上CSVのURL」）。

| 付け足す指定 | 取れる内容 |
|---|---|
| なし | 前日に利用があった分 |
| `&date=2026-11-21` | 指定した利用日の分 |
| `&from=2026-11-17&to=2026-11-23` | 期間（両端の日を含む・最長 366 日） |
| `&basis=payment` | カード決済の入金・返金を、お金が動いた日で並べた明細（入金の突き合わせ用） |

列（左から）:

| 列 | 内容 |
|---|---|
| 利用日 | 2026-11-17 の形（イベント参加費・登録料・更新料は決済された日） |
| 拠点 | みんなの体育館 ASP／みんなの体育館 やばせ |
| 売上種別 | 施設利用／イベント参加費／登録料／更新料／月会費／その他 |
| 施設 | 体育館／トレーニングルーム（貸切）／トレーニングルーム（相席） |
| 開始時刻 | 10:00 の形 |
| 利用時間 | 2時間 の形 |
| 予約者 | 氏名または団体名（イベント参加費は「イベント名／氏名」、登録料・更新料は「会員区分／氏名」） |
| 会員区分 | 一般／S-01（定期）など |
| 支払方法 | オンライン決済／請求書払い／無料／管理者登録／現金／振込 |
| 金額（税込） | 売上タブと同じ金額 |
| 金額（税抜） | 経理用CSV と同じ計算（1 件ごとに 税込÷1.1 を四捨五入） |
| 予約ID | 予約ごとの番号 |

その他の売上の行では、施設・開始時刻・利用時間・会員区分は空です。

定期団体の請求書払いも含みます（売上タブと一致させるため）。請求書払いを分けて扱う場合は「支払方法」の列で分けられます。

## 4. 管理画面で確かめる手順

1. 管理画面 → 売上タブ → 期間を 2026-11-17 〜 2026-11-23 にする
2. 合計売上が 93,775 円（23 件）と出ることを確かめる。その下に「うち その他の売上 15,400 円（4 件）」と出ます。日別の金額は上の表のとおり
3. 「RPA用 売上CSVのURL」を表示し、末尾に `&from=2026-11-17&to=2026-11-23` を付けて開く
4. ダウンロードした CSV の「金額（税込）」を日ごとに足し、2 の日別の金額と同じになることを確かめる
5. 銀行振込で受け取った分は、売上タブの「その他の売上」に入力すると、合計と CSV に同じ金額が増えます（入力した分は削除ボタンで消せます）

実際に取得した CSV を 3 つ、あわせてお送りします。

- `RPA用売上CSV_利用日_2026-11-17_2026-11-23.csv`（期間指定）
- `RPA用売上CSV_利用日_2026-11-21.csv`（1 日指定）
- `入金明細CSV_basis=payment_2026-11.csv`（お金が動いた日で並べた明細）
